---
title: 'Link To Event Or Registration Form Of Old Event'
published: true
---

If the Details or Register button opens an old or deleted event, the Events Booking router may be reusing a URL. Use one of these methods to correct the link.

1. Go to Events Booking -> Configuration and open the SEF Router Settings tab. Set Insert Event ID to Yes. The router adds each event’s ID to its URL so it doesn’t reuse a URL from an old or deleted event.
2. To keep event IDs out of URLs, go to Events Booking, then Tools -> Purge URLs to clear the cached URLs. Reopen the page listing the events and click the button again.
