---
title: 'Use Email Logs'
published: true
---

If an administrator or registrant doesn’t receive an email, use the Emails Logs feature to help identify the cause.

1. Go to Events Booking -> Configuration, set **Log Emails** config option to **Yes**
2. Then register for the event again. If the event is a paid event, you will need to pay for the subscription (or use offline payment method) for the email to be sent.
3. Open Events Booking, then Tools -> Emails Logs. There it will display logged emails:
- If the test email appears in the log, Events Booking called the Joomla API to send it. If the email didn’t arrive, try another email address. If it still doesn’t arrive, ask your hosting provider to check mail delivery.
- If the test email doesn’t appear in the log, submit a support ticket so we can investigate.
