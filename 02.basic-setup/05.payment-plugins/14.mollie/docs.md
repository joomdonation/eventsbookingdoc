## Installation

After purchasing the plugin, go to **Events Booking** -> **Payment Plugins** and install **os_eb_ideal.zip**. See [**Install Payment Plugin**](/basic-setup/payment-plugins#install-new-payment-plugin) for the steps.

## Configuration

Open the payment plugin, enter the required parameters, then publish the plugin and save your changes.
