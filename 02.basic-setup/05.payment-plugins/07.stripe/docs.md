## Installation

After purchasing the plugin, go to **Events Booking** -> **Payment Plugins** and install **os_eb_stripe.zip**. See [**Install Payment Plugin**](/basic-setup/payment-plugins#install-new-payment-plugin) for the steps.

## Configuration

Follow [Stripe's API key instructions](https://stripe.com/docs/keys#api-keys) to get the API keys for your Stripe account.

Open the payment plugin, enter the keys in the corresponding parameters, then publish the plugin and save your changes.
