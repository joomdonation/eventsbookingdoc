## Installation

After purchasing the plugin, go to **Events Booking -> Payment Plugins** and install **os_eb_paypal_pro.zip**. See [**Install Payment Plugin**](/basic-setup/payment-plugins#install-new-payment-plugin) for the steps.

## Configuration

Follow [PayPal's API signature instructions](https://developer.paypal.com/docs/archive/nvp-soap-api/apiCredentials/#api-signatures) to get the **API Username**, **API Password**, and **API Signature** for your PayPal account.

Open the payment plugin, enter these credentials in the corresponding parameters, then publish the plugin and save your changes.
