Set up PDF tickets, QR-code check-in, certificates, and name badges. You can also display Events Booking views in Joomla modules or configure a multilingual site.

- [Tickets PDF](/advanced-features/tickets-pdf)
- [Check-in Registrants using QRCODE](/advanced-features/check-in-registrants)
- [Certificates](/advanced-features/certificates)
- [EB View Module](/advanced-features/eb-view-module) — Display an Events Booking view in a module on versions older than 4.1.0.
- [Easy View Module](/advanced-features/easy-view-module) — Display an Events Booking view in a module using Easy View.
- [Multilingual](/advanced-features/multilingual) — Configure translated event content and extension text.
- [Name Badge](/advanced-features/name-badge)
