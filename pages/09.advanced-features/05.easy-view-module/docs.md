---
title: 'Easy View Module'
published: true
---

This is a special feature allow you to display a view in the extension (Calendar, Full Calendar, Upcoming events, Category, Event Detail, Registration Form of an event) inside a module on your site. (Normally, you will have to create a menu item to display a view in the extension)

1. Create a hidden menu item to link to the view which you want to display in the module. Setup necessary parameters in the menu item if needed (for example, if you use Upcoming Events menu item type, you might want to display events from certain categories only, this could be configured in menu item parameters)
2. Go to Extensions -> Modules, create a new instance of **Events Booking - Easy View** module, assign it to the position you want in the template. In the module, just set **Menu Item** to the menu item you created above.
