---
title: 'Cancel Event'
published: true
---

Follow these steps to cancel an event.

1. Go to **Events Booking** -> **Emails & Messages**, look at **Registration Email Messages** tab, configure subject and body of the email:

- Event Cancel Email Subject
- Event Cancel Email Body

2. Go to **Events Booking** -> **Events**, select the checkboxes for the events to cancel, and click **Actions -> Cancel** in the toolbar.

When you do that, the system will:

- Set the status of all registrants for that event to Cancelled.
- Set the event status to Cancelled and stop accepting registrations.
- Email all registrants to let them know the event is canceled.
