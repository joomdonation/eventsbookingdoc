Below are instructions for common custom fields assignment scenarios

**1. Fields available for all events**
- **Categories**: Set to **All Categories**
- **Field Assignment** : Set to **All Events**

**2. Fields available for all except some selected events**
- **Categories**: Set to **All Categories**
- **Field Assignment** : Set to **Exclude Selected Events**
- **Events** : Select the events which you want the field to be excluded.

**3. Fields available for events from certain categories**
- **Categories**: Select the categories you want
- **Field Assignment**: Set to **All Selected Events**
- **Events**: Do not select any events.

**4. Fields available for events from certain categories excluding some events**
- **Categories**: Select the categories you want
- **Field Assignment** : Set to **Exclude Selected Events**
- **Events** : Select the events which you want the field to be excluded.

**5. Fields available for certain events**
- **Categories**: Do not select anything.
- **Field Assignment** : Set to **Selected Events**
- **Events** : Select the events which you want the field to be available.
