# Basic Setup

Configure the categories, locations, and events you need to start accepting registrations. Use the remaining pages to set up registration fields, payments, messages, and other options.

- [Categories](/basic-setup/categories)
- [Locations](/basic-setup/locations) — Set up venues and map details for your events.
- [Events](/basic-setup/events)
- [Custom Fields](/basic-setup/custom-fields) — Choose what information to collect on registration forms.
- [Payment Plugins](/basic-setup/payment-plugins)
- [Tax Rules](/basic-setup/tax-rules) — Set event tax rates or define tax rules.
- [EU Tax Rules](/basic-setup/eu-tax-rules) — Set up the extension’s EU VAT options.
- [Coupons](/basic-setup/coupons)
- [Discount Bundle](/basic-setup/discount-bundles) — Offer a discount to users who register for all events in a bundle.
- [Emails & Messages](/basic-setup/emails-messages) — Customize notification emails and messages.
- [Invoicing Integration](/basic-setup/invoice-integration)
- [Enable Cancel Registration](/basic-setup/enable-cancel-registration)
- [Deposit Payment](/basic-setup/deposit-payment)
- [Setup Waiting List](/basic-setup/waiting-list)
- [Setup Reminder](/basic-setup/auto-reminder) — Send email reminders before an event starts.
- [Newsletter Integration](/basic-setup/newsletters-integration)
- [Synchronize Profile Data](/basic-setup/synchronize-profile-data) — Share registrant details with supported Joomla profile integrations.
- [Enable Captcha](/basic-setup/enable-captcha)
- [Conversion Tracking Code](/basic-setup/conversion-tracking-code)
- [GDPR](/basic-setup/gdpr)
- [Countries & States](/basic-setup/countries-states) — Configure the country and state lists used on registration forms.
- [SMS Reminders](/basic-setup/sms-reminder)
- [Conditional Text](/basic-setup/conditional-text) — Show text in messages and documents when a condition is met.
- [Translation](/basic-setup/Translation) — Edit the wording used by the extension.
