**Events Booking** is a powerful, features rich, easy to use Joomla Events Registration extension. It allows you to create events (both free and paid), allows registrants to register for these events (Individual or Group registration) and process payment via online payment gateways such as Paypal, Authorize.net, Eway, WorldPay, Stripe, Mollie, 2Checkout, First Data....For detailed information about the product, please visit [https://joomdonation.com/joomla-extensions/events-booking-joomla-events-registration.html](https://joomdonation.com/joomla-extensions/events-booking-joomla-events-registration.html)
