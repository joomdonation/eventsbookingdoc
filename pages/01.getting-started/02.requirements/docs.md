**Events Booking** is a Joomla extension, so you need to have a website built on [Joomla CMS](https://joomla.org) to use the extension. Please look at [https://joomla.org/about-joomla/technical-requirements.html](https://joomla.org/about-joomla/technical-requirements.html) to see technial requirement for your server. Latest version of Events Booking only works with **Joomla 3.9.0+**. If you are using older Joomla version, submit a support ticket asking us sending old version of the extension which works with these old Joomla versions.

Beside generic requirement with a Joomla website, **Events Booking** also requires some additional requirements below:

1.  **PHP 7.2.0+**. If your site is running on older version of PHP, please contact your hosting provider, ask them to change settings for your hosting account to use PHP 7.2.0+. If you cannot use PHP 7.2.0+ for some reasons, submit a support ticket asking us to send you Events Booking 3.17.6 (or older) which only requires PHP 5.4.0+.
2.  If you use a credit card based payment plugins (for example, Paypal Pro, Authorize.net, Eway, NAB Transact, Stripe...), customers will enter credit card information directly on your site for processing payment, so your site should **have an SSL certificate installed** so that the payment process will be secure. Without an SSL certificate, Events Booking still works well, however, in this case, the credit card data which customers enter on your site for processing payment won't be encrypted when it is transferred over internet, and it will be insecure.
