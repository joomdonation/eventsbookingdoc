This plugin adds [Google Structured Data](https://developers.google.com/search/docs/guides/intro-structured-data) to events list and event details page. The purpose is helping Google to understand event data better and provide better search result

If you want to use this feature, go to **System** -> **Plugins**, find and enable the plugin **Events Booking - Google Structured Data**.
