---
title: 'Coupon is not available on registration form'
---

If the coupon field is missing from the registration form, check these settings.

1. You haven't enabled coupon feature yet. Go to Events Booking -> Configuration, check and make sure **Enable Coupon** parameter set to Yes.
2. Make sure at least one valid coupon is available for the event.
- Check **Coupon Assignment**. Select All Events, or use All Selected Events and confirm that the event is selected in the Event setting.
- Check that today falls between the coupon’s **Valid From Date** and **Valid To Date**. You can also leave both settings empty.
- Check Access setting of the coupon, try to change it to Public.
