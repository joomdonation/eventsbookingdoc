**Events Booking** requires a website built with [Joomla CMS](https://joomla.org). Check the Joomla technical requirements for your server at [https://joomla.org/about-joomla/technical-requirements.html](https://joomla.org/about-joomla/technical-requirements.html). Latest version of Events Booking only works with **Joomla 3.9.0+**. If you are using older Joomla version, submit a support ticket asking us sending old version of the extension which works with these old Joomla versions.

In addition to Joomla’s general requirements, **Events Booking** has the following requirements.

1.  **PHP 7.2.0+**. If your site is running on older version of PHP, please contact your hosting provider, ask them to change settings for your hosting account to use PHP 7.2.0+. If you cannot use PHP 7.2.0+ for some reasons, submit a support ticket asking us to send you Events Booking 3.17.6 (or older) which only requires PHP 5.4.0+.
2.  If you use a payment plugin such as PayPal Pro, Authorize.net, Eway, NAB Transact, or Stripe to accept card details directly on your site, **have an SSL certificate installed**. Events Booking can still run without a certificate, but the card details customers submit will travel over the internet without encryption.
