If importing or exporting events or registrants produces a PHP error, the ZIP library may be disabled on your hosting account. Check the two options below.

1. If you just want to export subscriptions, go to Events Booking -> Configuration, set Export Data Format config option to CSV. Then try again, export should work
2. To import registrants or events, or to export data to Excel, ask your hosting provider to enable the ZIP library. You can send them this link: http://php.net/manual/en/zip.installation.php
