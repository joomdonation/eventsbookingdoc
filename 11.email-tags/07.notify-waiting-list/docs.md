---
title: 'Notify Waiting List Email'
published: true
---

When a registrant or an administrator cancels a registration, Events Booking emails people on the waiting list to tell them a place is available.

To edit the email, go to Events Booking -> Emails & Messages and open **Waiting List Messages**. Edit **Waiting List Notification Email Subject** and **Waiting List Notification Email Body**.

## Supported Tags
[REGISTRANT_FIRST_NAME] : First Name of the registrant who cancel registration
[REGISTRANT_LAST_NAME] : Last Name of the registrant who cancel registration
[EVENT_LINK] : Link to the event (you can access to that link to see event details page and perform registration from there)
[EVENT_TITLE]
[EVENT_DATE]
[EVENT_END_DATE]

[FIRST_NAME] : First Name of the waiting list user who the email is sent to.
[LAST_NAME] : Last Name of the waiting list user who the email is sent to.
