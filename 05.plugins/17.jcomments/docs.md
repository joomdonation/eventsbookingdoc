If you use the [JComments extension](http://www.joomlatune.com/jcomments-plugins.html), this plugin lets visitors comment on Events Booking event details pages.

So if you use JComments extension on your site and want to enable users to add comments to your events, go to **System -> Plugins**, find and publish the enable **Events Booking - Jcomments** plugin.
