### Miscellaneous plugins

Use Events Booking plugins to add features to event pages, automate registration-related tasks, and integrate with Joomla and other services.

- [Ticket Types](/plugins/ticket-types)
- [Additional Dates](/plugins/additional-dates) — Add dates to an existing event.
- [Joomla Groups Integration](/plugins/joomla-groups-integration) — Assign Joomla user groups based on event registration.
- [Prevent Overlap Registration](/plugins/prevent-overlap-registration)
- [Event Dependencies](/plugins/event-dependencies) — Require registration for another event first.
- [Emails Restriction](/plugins/emails-restriction) — Restrict registrations by email address.
- [Attachments](/plugins/attachments) — Upload multiple event attachments.
- [Map](/plugins/map-plugin) — Display a map on the event details page.
- [Speakers](/plugins/speakers)
- [Agendas](/plugins/agendas)
- [Sponsors](/plugins/sponsors-plugin)
- [Gallery](/plugins/gallery)
- [Related Events](/plugins/related-events)
- [Registrant List](/plugins/registrants-list) — Display the registrant list on the event details page.
- [Waiting List](/plugins/waiting-list) — Display the waiting list on the event details page.
- [Jcomments](/plugins/jcomments)
- [Zoom Integration](/plugins/zoom-integration)
- [Google Structured Data](/plugins/google-structured-data)
- [Coupon Generator](/plugins/coupon-generator) — Send a coupon code after registration.
- [Group Member Account](/plugins/group-member-account) — Create accounts for group members.
- [Auto Group Members](/plugins/auto-group-members) — Generate group members without entering their details individually.
- [Auto Registration](/plugins/auto-registration) — Register users for additional events automatically.
- [Auto Membership](/plugins/auto-membership) — Subscribe registrants to Membership Pro plans.
- [Move Registrants](/plugins/move-registrants) — Move people from a waiting list after a cancellation.
- [Offline Payment Handle](/plugins/offline-payment-handle) — Find the scheduled task that replaced this plugin.
- [MPDF](/plugins/mpdf) — Use mPDF to generate PDFs.
- [Webhook](/plugins/webhook) — Send registration data to an external URL.
- [Additional Event Managers](/plugins/additional-event-managers)
- [Checked In Notification](/plugins/checked-in-notification)
- [Assign Checked-in Registrants To User Groups](/plugins/assign-checked-in-registrants-to-user-groups)
- [Fields Assignment](/plugins/fields-assignment) — Assign existing custom fields from the event form.
- [Content - Category](/plugins/content-category) — Embed events from a category in Joomla content.
- [Content - Event](/plugins/content-event) — Embed a single event in Joomla content.
- [Content - Registration Form](/plugins/content-registration-form) — Embed an event’s registration form in Joomla content.
- [Content Restriction](/plugins/content-restriction) — Restrict Joomla content based on event registration.
- [Content Speakers](/plugins/content-speakers)
- [User - Events Booking](/plugins/user-events-booking) — Find settings for the Events Booking user plugin.
- [Smart Search](/plugins/smart-search) — Make Events Booking events searchable through Joomla Smart Search.
- [Actions Log](/plugins/actions-log)
- [New Events Notification](/plugins/new-events-notification)
- [Full Event Notification](/plugins/full-event-notification)
- [Failure Payment Notification](/plugins/failure-payment-notification)
- [Google Analytics Purchase](/plugins/google-analytics-purchase) — Send purchase events to Google Analytics.
- [Meta Pixel Purchase](/plugins/meta-pixel-purchase) — Send purchase events to Meta Pixel.
