---
title: 'Content Speakers'
published: true
---

Display speakers from one event or from all events in a Joomla article or any other place that runs content plugins, such as a Custom HTML module.

If you want to use this feature:
1. Go to Extensions, Plugins, find and enable the plugin **Content - Events Booking Speakers**
2. Edit the article you want to display speakers, enter this syntax **{ebspeakers ID_OF_EVENT}**. **ID_OF_EVENT** needs to be replaced with ID of the event you want to display (or 0). For example:

{ebspeakers 1} will display speakers of event with ID = 1

{ebspeakers 0} will display speakers of all events.
